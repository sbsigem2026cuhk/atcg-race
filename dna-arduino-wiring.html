Breadboard wiring

Arduino Uno · four 3-pin buttons (UCC, GND, SW) · half-size breadboard · jumpers

What each pin means

LabelConnect to
UCC (VCC)5 V power (same node for all four keys)
GNDGround (same node for all four keys)
SWOne signal wire per key → a different Arduino digital pin

Power rails on the breadboard

  1. Plug the Arduino Uno into USB so you can reference pin labels, or work from the pin names printed on the board.
  2. Use a jumper from Arduino 5V → the breadboard’s red (+) rail running along one long edge.
  3. Use a jumper from Arduino GND → the breadboard’s blue (−) rail on the same side (or opposite side if that matches your habit—just keep +/− consistent).

If your breadboard has split rails (a gap in the middle of the long strip), add a small jumper so both halves of the red rail are connected to 5V, and both halves of blue to GND.

Each of the four keys

For every button module:

  • UCC → any hole on the red 5V rail.
  • GND → any hole on the blue GND rail.
  • SW → a free row on the breadboard (same row on both sides of the center groove if you bridge with a component; usually you use one row and a jumper to the Arduino).

From each SW row, run a jumper to the Arduino:

Key (base)SW → Arduino
ADigital 2 (D2)
TDigital 3 (D3)
CDigital 4 (D4)
GDigital 5 (D5)

Start (no extra wire)

Press and hold all four keys (A+T+C+G) at the same time for about 0.15 seconds. The Arduino sends a start signal to the page. You can still start from the keyboard with Space.

After wiring

  • Upload dna_sequence_game.ino (115200 baud).
  • Open dna-arduino.html in Chrome/Edge and connect the serial port.

If a key reads backwards (always “pressed”), your module might use opposite logic—say so and the sketch can be adjusted (INPUT vs INPUT_PULLUP or inverted reads).
